# Dashboard do PSM

Evolução do projeto inteiro nas três categorias de informação do [Plano de medição](plano-de-medicao.md): Calendário e Progresso, Recursos e Custos e Desempenho dos Processos. A página é gerada a cada publicação do site, com os mesmos dados do [Painel do PSM](painel-psm.md); passe o mouse sobre os gráficos para ver os valores. A interpretação de cada medição está no [Registro de medições](registro-de-medicoes.md).
