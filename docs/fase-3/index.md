# Fase 3: Projetar a avaliação

A Fase 3 transforma a especificação da [Fase 2](../fase-2/index.md) em um plano de avaliação: métodos, instruções para o avaliador, recursos e ambiente de cada característica. A avaliação usa o draw.io web 32.6.10, executado localmente a partir de um fork feito pelo membro Heyttor Augusto. A [execução, as medidas e os resultados](../fase-4/index.md) pertencem à Fase 4.

O cronograma da avaliação segue o [planejamento das sprints](../gestao/planejamento.md): Sprint 4 (07/11 a 16/11), projeto e coleta; Sprint 5 (17/11 a 22/11), conclusão, revisão e entrega.
