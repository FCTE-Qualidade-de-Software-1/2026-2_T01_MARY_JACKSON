# Dados

- `gestao/`: registro de horas e estimativa de custos (PSM/CID).
- `avaliacao/`: dados coletados na avaliação (Fase 4), sem tratamento, e dados consolidados.

Dados de participantes entram só depois de anonimizados.

As [evidências de eficiência de desempenho](avaliacao/eficiencia/README.md) têm instruções de acesso aos pacotes externos de traces, restauração e conferência de integridade. Os CSVs, scripts e cargas permanecem versionados no Git.
